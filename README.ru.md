# Hunter Aggro Meter (Solo MODE)

*[Read this in English](README_en.md)*

Небольшой аддон для WoW для охотников, которые соло-фармят с петом-танком/ДД. Показывает, насколько **ты** близок к тому, чтобы перетянуть агро с пета — одной полосой с меткой-порогом, плюс помощник по Feign Death.

## Для кого это

Аддон писался и тестировался на **приватном сервере, работающем на движке уровня ванильного WoW 1.12** (не официальный клиент Blizzard Classic Era). Он сам определяет, какой API реально доступен на твоём сервере, и подстраивается:

- **Если на сервере есть настоящий API угрозы** (`UnitDetailedThreatSituation`, появился в официальном патче Classic Era 1.13.5): аддон показывает *реальную* угрозу относительно пета. Точно.
- **Если его нет** (чистая ванилла 1.12 и большинство ванильных приватных серверов): аддон прикидывает угрозу, сравнивая твой урон с уроном пета через боевой лог в чате. Это **приблизительная оценка**, а не настоящие данные об угрозе — воспринимай как полезный индикатор, а не гарантию.

Если ты на официальном клиенте Classic Era — аддон просто заработает в точном режиме автоматически, ничего настраивать не нужно.

## Возможности

- Одна сравнительная полоса: твоя угроза (или доля урона) относительно пета, с настраиваемой меткой-порогом.
- Справочная полоса пета и статус-строка "кто сейчас танкует".
- Хил пета (Mend Pet) тоже считается угрозой (50% от объёма лечения) — так что случайно переагрить чистым спамом хила не получится незаметно.
- **Поддержка Feign Death**: при активации FD текущий процент агро запоминается, полоса падает до 0 с отсчётом на экране. Первое действие после FD восстанавливает агро по затухающей формуле (чем раньше действуешь — тем больше восстанавливается).
- Перетаскиваемое окно, постоянная кнопка-переключатель, настраиваемый порог агро, и внутриигровое окно-справка "Rules - read me!".
- Настройки сохраняются между заходами в игру.

## Установка

1. Скачай этот репозиторий как ZIP (зелёная кнопка "Code" → "Download ZIP"), либо возьми последний ZIP со страницы [Releases](../../releases), если она есть.
2. Распакуй так, чтобы в итоге получилась папка `HunterAggroMeter` прямо внутри твоей папки `Interface\AddOns\`:
3. 
World of Warcraft\Interface\AddOns\HunterAggroMeter\HunterAggroMeter.toc
World of Warcraft\Interface\AddOns\HunterAggroMeter\HunterAggroMeter.lua
...

3. Перезапусти игру (или `/reload`) и убедись, что аддон включён в списке AddOns на экране выбора персонажа.

## Команды

Все команды начинаются с `/ham` (или `/aggro`):

| Команда | Что делает |
|---|---|
| `/ham` | Показать список команд |
| `/ham show` | Показать окно |
| `/ham hide` | Скрыть окно |
| `/ham lock` | Заблокировать/разблокировать перетаскивание окна |
| `/ham sound` | Вкл/выкл звуковое предупреждение об агро |
| `/ham reset` | Сбросить позицию окна |
| `/ham t <число>` | Установить порог перетягивания агро, например `/ham t 180` |
| `/ham doc` | Показать внутриигровое окно "Rules - read me!" |

Также есть маленькая кнопка "H", которая всегда видна на экране (Ctrl+перетаскивание — подвинуть, Ctrl+ПКМ — сбросить её позицию) — ЛКМ по ней открывает/закрывает главное окно.

## Известные ограничения

- На ванильных серверах это **приблизительная оценка угрозы по урону, а не настоящие данные**. У разных способностей разные реальные коэффициенты угрозы, которых аддон не видит.
- Название события для отслеживания хила пета (Mend Pet), дающего бонус к угрозе, официально не задокументировано для клиентов уровня 1.12; зарегистрировано несколько вероятных вариантов имени события как лучшая попытка. Если бонус за хил пета не срабатывает на твоём сервере — сообщи через Issues.
- Отсчёт Feign Death показывается в фиксированной точке экрана (API "прикрепить текст к 3D-модели персонажа" у аддонов нет), поэтому позиция "под персонажем" приблизительна и рассчитана на стандартную камеру от третьего лица.

## Заметки по тестированию

Аддон предназначен для удобства игры охотником в соло моде — для контроля срыва агро с пета.

Тестировался с 20 по 33 уровень. Настройки порога, использованные во время тестов:

- Уровень 20: `/ham t 190`
- Уровень 27+: `/ham t 210`
- Уровень 30+: `/ham t 230`

Как будет дальше — пока не известно. Возможно, на более высоких уровнях логику работы придётся переделывать более принципиально.

## Как изменить текст окна Rules

Текст, который показывает `/ham doc`, лежит в `RulesText.lua` (Lua-строка). Для удобного чтения/редактирования есть копия в виде обычного текста — `Rules_read_me.txt`. WoW-аддоны не могут читать произвольные файлы с диска во время игры, поэтому если редактируешь `.txt` — скопируй те же изменения в `RulesText.lua`, иначе в игре текст не обновится.
